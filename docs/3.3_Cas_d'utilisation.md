# 3.3 Cas d'utilisation

Les cas d'utilisation permettent de formaliser les différentes interactions entre les acteurs et l'application Spotly. Ils permettent d'identifier les fonctionnalités accessibles aux utilisateurs et à l'administrateur, ainsi que les actions nécessaires à la réalisation des principaux parcours.

Les cas d'utilisation présentés ci-dessous sont définis à partir des besoins identifiés dans l'expression du besoin et des contraintes fonctionnelles du projet.

## 3.3.1 Cas d'utilisation de l'utilisateur

L'utilisateur représente le voyageur utilisant Spotly pour découvrir et partager des expériences locales.

| Cas d'utilisation                   | Description                                                                                                           |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **S'inscrire**                      | Créer un compte afin d'accéder aux fonctionnalités nécessitant une authentification.                                  |
| **Se connecter**                    | S'authentifier afin d'accéder à son compte et à ses fonctionnalités personnelles.                                     |
| **Gérer son profil**                | Consulter et modifier les informations de son compte.                                                                 |
| **Consulter les spots à proximité** | Afficher les spots disponibles autour de sa position.                                                                 |
| **Utiliser sa localisation**        | Autoriser Spotly à utiliser sa position afin de proposer des spots à proximité.                                       |
| **Définir son temps disponible**    | Indiquer le temps dont il dispose afin d'identifier des expériences compatibles avec cette contrainte.                |
| **Rechercher un spot**              | Rechercher une expérience à partir de critères ou de mots-clés.                                                       |
| **Filtrer les spots**               | Affiner les résultats selon différents critères, notamment la catégorie, la durée ou la distance.                     |
| **Consulter le détail d'un spot**   | Consulter les informations détaillées d'une expérience : description, localisation, durée, photos, catégorie et tags. |
| **Créer un spot**                   | Ajouter une nouvelle expérience locale à la plateforme.                                                               |
| **Modifier un spot**                | Modifier les informations d'un spot dont l'utilisateur est l'auteur.                                                  |
| **Supprimer un spot**               | Supprimer un spot dont l'utilisateur est l'auteur.                                                                    |
| **Ajouter un spot aux favoris**     | Enregistrer un spot afin de pouvoir le retrouver ultérieurement.                                                      |
| **Consulter ses favoris**           | Consulter les spots enregistrés dans ses favoris.                                                                     |
| **Retirer un spot des favoris**     | Supprimer un spot de sa liste de favoris.                                                                             |
| **Commenter un spot**               | Ajouter un retour d'expérience ou un commentaire sur un spot.                                                         |
| **Signaler un contenu**             | Signaler un spot ou un commentaire qui ne respecte pas les règles de la plateforme.                                   |

## 3.3.2 Cas d'utilisation de l'administrateur

L'administrateur assure la gestion et la modération de la plateforme.

| Cas d'utilisation                   | Description                                                                                                            |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Se connecter à l'administration** | S'authentifier afin d'accéder aux fonctionnalités d'administration.                                                    |
| **Consulter les utilisateurs**      | Consulter les comptes présents sur la plateforme.                                                                      |
| **Gérer les utilisateurs**          | Effectuer les actions de gestion prévues sur les comptes utilisateurs.                                                 |
| **Consulter les spots**             | Consulter les spots créés par la communauté.                                                                           |
| **Modérer un spot**                 | Vérifier un spot et, si nécessaire, le modifier ou le supprimer lorsqu'il ne respecte pas les règles de la plateforme. |
| **Consulter les commentaires**      | Consulter les commentaires publiés par les utilisateurs.                                                               |
| **Modérer un commentaire**          | Modifier ou supprimer un commentaire ne respectant pas les règles de la plateforme.                                    |
| **Consulter les signalements**      | Consulter les contenus signalés par les utilisateurs.                                                                  |
| **Traiter un signalement**          | Analyser un signalement et prendre les mesures appropriées.                                                            |

## 3.3.3 Fonctionnalité principale : découvrir une expérience locale

Le cas d'utilisation principal de Spotly est :

> **Découvrir une expérience locale adaptée à sa situation**

Il constitue le cœur fonctionnel de l'application et répond directement à la problématique définie dans l'expression du besoin :

> **« Comment permettre à un voyageur de trouver rapidement une activité ou une expérience locale pertinente, à proximité de sa position et adaptée au temps dont il dispose ? »**

La découverte contextualisée repose principalement sur plusieurs informations :

* la position de l'utilisateur ;
* le temps disponible ;
* la distance ;
* les préférences et critères de recherche.

Ces informations permettent de réduire les résultats proposés à l'utilisateur et de faciliter sa prise de décision.

## 3.3.4 Déroulement du cas d'utilisation principal

Le scénario nominal de découverte d'une expérience est le suivant :

1. L'utilisateur ouvre Spotly.
2. L'application lui demande l'autorisation d'accéder à sa localisation.
3. L'utilisateur autorise l'accès à sa position.
4. Spotly récupère sa position.
5. L'utilisateur indique le temps dont il dispose.
6. L'application recherche les spots correspondant à sa situation.
7. Les spots pertinents sont affichés sur la carte et/ou sous forme de liste.
8. L'utilisateur peut appliquer des filtres supplémentaires.
9. L'utilisateur sélectionne un spot.
10. Spotly affiche les informations détaillées de l'expérience.
11. L'utilisateur choisit l'expérience qui correspond le mieux à sa situation.

Ce parcours constitue le scénario nominal de la fonctionnalité principale.

Des scénarios alternatifs seront également pris en compte lors de la conception détaillée, notamment lorsque :

* l'utilisateur refuse l'accès à sa localisation ;
* aucun spot ne correspond aux critères sélectionnés ;
* les données de localisation ne peuvent pas être récupérées ;
* les résultats disponibles sont insuffisants.

## 3.3.5 Organisation des cas d'utilisation

Les différents cas d'utilisation peuvent être regroupés en plusieurs domaines fonctionnels :

### Découverte

* Consulter les spots à proximité
* Utiliser sa localisation
* Définir son temps disponible
* Rechercher un spot
* Filtrer les spots
* Consulter le détail d'un spot

### Gestion du compte

* S'inscrire
* Se connecter
* Gérer son profil

### Contribution communautaire

* Créer un spot
* Modifier un spot
* Supprimer un spot
* Commenter un spot
* Ajouter un spot aux favoris
* Consulter ses favoris
* Retirer un spot des favoris
* Signaler un contenu

### Administration et modération

* Se connecter à l'administration
* Consulter les utilisateurs
* Gérer les utilisateurs
* Consulter les spots
* Modérer un spot
* Consulter les commentaires
* Modérer un commentaire
* Consulter les signalements
* Traiter un signalement

Cette organisation permet de distinguer clairement la fonctionnalité principale de découverte des fonctionnalités secondaires nécessaires au fonctionnement communautaire de la plateforme.

## 3.3.6 Diagramme de cas d'utilisation

À partir des cas d'utilisation identifiés, un diagramme UML sera réalisé afin de représenter visuellement les interactions entre les acteurs et les fonctionnalités de Spotly.

Le diagramme permettra notamment de mettre en évidence le rôle de l'utilisateur et de l'administrateur ainsi que les relations entre les différents cas d'utilisation.

Le cas d'utilisation **« Découvrir une expérience locale adaptée à sa situation »** sera placé au centre de la représentation afin de mettre en évidence son importance dans le fonctionnement de l'application.
